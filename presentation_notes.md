# DisasterAI — demo talking points

## Opening (20 seconds)
"DisasterAI is an academic prototype for explainable disaster assessment. The full proposal combines imagery, environmental time series, and disaster reports. For this demonstration, I am validating the image-segmentation component first."

## Experiment 1: traditional baseline (30 seconds)
"This is a threshold-based SAR reference method. It uses backscatter intensity and selects threshold/polarity on the validation set. It is simple and fast, but it may confuse permanent water, shadows/noise, and other dark surfaces."

## Experiment 2: vanilla U-Net (30 seconds)
"This is a standard encoder-decoder segmentation model with skip connections. All weights start from random initialization. It learns pixel-level masks from training images and labels."

## Experiment 3: proposed method (40 seconds)
"My proposed variant adds attention gates to the U-Net skip connections so the decoder can weight spatial features selectively; input-gradient saliency is shown as a diagnostic, not proof of causal reasoning. This is a hypothesis, not a guaranteed improvement. I compare it with the vanilla U-Net on the same held-out test examples."

## Metrics (30 seconds)
"Here are the measured IoU, Dice, precision, recall, and pixel accuracy from this run. The threshold was selected using validation data; the neural checkpoints were selected by validation loss. Test metrics were computed after checkpoint selection."

## Honest limitations (20 seconds)
"This is currently the vision/segmentation component. Environmental forecasting, text understanding, multimodal event matching, and broader robustness evaluation remain separate work unless explicitly shown in the implemented results. Synthetic smoke-test results, if any, are not real disaster results."

## Before presenting
- Use `outputs/metrics.csv` generated by your actual run.
- Keep a screenshot of `outputs/predictions.png`, `outputs/unet_predictions.png`, and `outputs/proposed_predictions.png`.
- Do not quote numbers from another repository as if you reproduced them.
- If training is incomplete, label the results as a smoke test or preliminary run.
